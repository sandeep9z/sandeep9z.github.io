Backstage golden path

End-to-end automation from a single form. An engineer picks a template and gets a repository, infrastructure, deployment and pipeline, all registered in the catalog. A Kubernetes operator reconciles the service environment.
  • Backstage
  • Go operator
  • Terraform
  • Helm
  • ArgoCD
  • Artifactory
# template.yaml (scaffolder, outline)
apiVersion: scaffolder.backstage.io/v1beta3
kind: Template
metadata:
  name: golden-path-service
  title: New service (golden path)
spec:
  owner: platform-team
  type: service
  parameters:
    - title: Service details
      required: [name, owner, lane]
      properties:
        name:  { type: string }
        owner: { type: string, ui:field: OwnerPicker }
        lane:  { type: string, enum: [compass, express-lane] }
  steps:
    - id: scaffold
      action: fetch:template
      input: { url: ./skeleton, values: "${{ parameters }}" }
    - id: repo
      action: publish:github
      input: { repoUrl: "github.com?owner=example-org&repo=${{ parameters.name }}" }
    - id: infra
      action: platform:terraform-pr    # custom action
      input: { service: "${{ parameters.name }}" }
    - id: deploy
      action: platform:argocd-app      # custom action
      input: { service: "${{ parameters.name }}", env: dev }
    - id: pipeline
      action: platform:attach-lane     # compass or express-lane
      input: { lane: "${{ parameters.lane }}" }
    - id: register
      action: catalog:register
      input: { catalogInfoUrl: "${{ steps.repo.output.remoteUrl }}" }
What the engineer gets, with no tickets
  • A repository with branch protection, CODEOWNERS, secret scanning and a working CI pipeline.
  • Infrastructure from reviewed Terraform modules, applied by the pipeline, with outputs published back to the catalog.
  • A running Dev deployment through a Helm chart and an ArgoCD application, with the image stored in Artifactory.
  • The release lane they chose. Compass for regular releases or Express Lane for no-op changes, already wired and green.
  • A catalog page showing owner, docs, dashboards, pipeline runs and deployment health in one place.
  • Every step is a commit. The scaffolder, Terraform and ArgoCD changes are all reviewable pull requests, so the result is auditable and repeatable.
